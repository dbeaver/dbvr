Installing dbvr
========================
  Use automatic installer distribution (Windows and Linux versions) or just unpack the archive and run the `dbvr` executable.

  Note: Do not extract the archive in the same folder where an older version of DBeaver is installed.
  Remove the previous version or extract the archive to another folder.

  It is recommended to add dbvr to your system PATH for easier command-line use. The procedure varies by operating system.
    - macOS: add the path to the dbvr executable to your shell profile.
      The executable is located inside the ${dbeaver-product}.app bundle at /path/to/${dbeaver-product}.app/Contents/MacOS.
      Additionally, you can use the provided script to add dbvr to your PATH.
      You can execute it with the command `/path/to/%ADD_TO_PATH_SCRIPT_PATH*`.
